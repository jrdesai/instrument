# Box Shadow Builder

Build layered CSS `box-shadow` values with a live preview.

## What it does

- Adds, removes, and reorders up to 6 shadow layers
- Supports `x`, `y`, `blur`, `spread`, `inset`, and colour + opacity per layer
- Shows a real-time preview and generated `box-shadow` CSS output
- Provides copy actions for both:
  - Value only (e.g. `2px 4px 8px 0px #00000040`)
  - Full property (e.g. `box-shadow: 2px 4px 8px 0px #00000040;`)

## Notes

- Pure frontend tool (no Rust command)
- Available on both desktop and web
